README — CSC 480 Final Project

This submission includes all notebooks, dataset files, model outputs, and the final NeurIPS-style report for my project on forecasting Wikipedia web traffic using 
LightGBM, LSTM, and an ensemble approach. All notebooks were originally run in Google Colab, where I mounted my Google Drive for file storage. Because of this, some 
cells reference paths such as /content/drive/MyDrive/CSC480/Final Project/. If you run the notebooks locally or in a different environment, please update these paths 
to match your own directory structure. To make grading easier, I have also included PDF versions of all notebooks with full outputs, along with all result CSV files 
(LightGBM predictions, LSTM predictions, ensemble predictions, and SMAPE scores), so you do not need to rerun the models unless desired.

All project components are organized into clear folders: notebooks, data, results, and the final report. If any issues occur due to file paths or environment differences,
simply adjust the directory in the notebook or refer to the pre-exported PDFs and result files.
